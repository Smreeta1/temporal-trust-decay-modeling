# Temporal Trust-Decay Modeling in Social Networks

## Description
Current misinformation diffusion models rely heavily on static, historical thresholds to classify users as trustworthy. This approach ignores temporal heterogeneity—the reality that user sharing habits change over time. This repository contains a time-series predictive pipeline that combines behavioral analytics (temporal sharing velocity) with Natural Language Processing (NLP) to model dynamic trust-decay. The goal is to establish a robust proxy for continuous model recalibration, spotting accounts degrading into misinformation "superspreaders" before their content peaks.
